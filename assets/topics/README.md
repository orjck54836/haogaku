# 主題照片

把照片放在這個資料夾，然後到 `src/ui/images.ts` 登記，主題頁的橫幅和主題卡就會換成照片。
沒登記的主題自動退回單元編號（`src/ui/seal.tsx` 的 `UnitBlock`），少一張不會開天窗。

目前 **86 張**：83 個主題全部有圖，加上五十音基礎（`basics.jpg`）
和兩張介面用圖（`../ui/coach.jpg`、`../ui/review.jpg`）。詳見 [CREDITS.md](CREDITS.md)。

- 寬 1000px、JPEG、單張 200KB 上下（`sips -Z 1000 -s formatOptions 58`）
- 檔名用主題 id，例如 `ramen.jpg`（id 看 `src/content/topics.ts`）
- 分類的代表照片用 `cat-` 開頭，例如 `cat-food.jpg`
- **只放自己拍的或有商用授權的圖**。App Store 審查會看版權

## 換圖或加圖時

照著 CREDITS.md 的兩條硬規則做，並把來源和判斷一起記上去：

1. **不要可辨識的人臉**。Pexels／Unsplash 的授權不含肖像權（model release）
2. **不要可辨識的第三方商標**

搜尋頁的文字描述**看不出**這兩件事——每一張都要下載下來親眼確認。
CREDITS.md 末尾有 37 筆否決紀錄，可以先掃一遍免得重蹈覆轍；
最常踩到的是商標、拍錯國家（中國／義大利／德國／泰國的場景混進來）、人臉。

## 拍不到本體的主題怎麼配圖

用意象相近的物件，不要硬找人物照。已經在用的對應：

| 主題 | 用什麼代替 |
|---|---|
| 自我介紹 | 空白名片 |
| 道謝與道歉 | 封蠟的手寫信 |
| 相槌與附和 | 耳機 |
| 擬聲擬態語 | 氣泡特寫 |
| 關西腔 | 章魚燒 |
| 常體與敬體切換 | 兩扇錯開的障子門 |
| 便利商店 | 便當盒（躲開招牌） |
| 動漫與宅文化 | 整牆的書脊（扭蛋機和秋葉原都躲不開商標） |

縮到卡片大小還看得清楚主體才算數——曾經選過一張球鞋只佔畫面一角的照片，
在實機上整張看起來像沒載入，後來換掉了。

## 照片當底圖時的兩個坑

首頁的捷徑磚和站名牌是「照片鋪底＋白字壓在上面」，踩過兩個版面問題，
都寫在 `src/ui/index.tsx` 的註解裡：

1. **鋪底的 `<Image>` 一定要給 `width`/`height`**，不能只下四邊的 inset——
   圖片有自己的內建尺寸，只給 inset 會照內建尺寸放大成局部特寫。
   而且 `height: '100%'` 需要父層有**確定高度**，靠 padding 撐出來的 auto 高度算不出來。
2. **父層有左右 padding 時，絕對定位子層的 `width: '100%'` 算的是內容區寬度**，
   右邊會露出一條底色。padding 要放在內層的文字容器上。

遮罩一律是**單層平光**。專案沒裝漸層套件，用多層矩形去模擬漸層的話，
邊界在實機上就是幾條看得見的灰帶。淺色照片（例如習字紙）改用 `photoScrim` 壓重一點。
